# Air Monitor: локальная сборка

Запуск из PowerShell в корне проекта: `powershell -ExecutionPolicy Bypass -File .\start.ps1`.
Карта: http://127.0.0.1:8000/ . API: http://127.0.0.1:8000/docs .
Если сервер уже запущен, второй экземпляр запускать не нужно.

## Что объединено

FastAPI раздаёт Leaflet-карту и общий адаптер `/web/api.js` с одного адреса.
Адаптер читает страницы `/api/v1/measurements`, убирает повторы UUID,
показывает только точки с координатами и переводит отсутствие калибровки в `unknown`.
Ошибки сервера больше не заменяются демонстрационными данными.
В карте есть импорт JSON (объект measurements или массив записей), результат по принятым,
повторным и отклонённым строкам. API key вводится в интерфейсе и хранится в sessionStorage.
Период по умолчанию — последние 24 часа; для старых измерений выберите «Барлығы».
Библиотека Leaflet и OSM-тайлы загружаются из интернета.

## Различия исходных проектов

| Исходный контракт frontend | Принято в интеграции |
| --- | --- |
| items + air_quality | Адаптер к measurements + processed backend |
| errors в sync | results с index/status/details; Android обрабатывает accepted/duplicate |
| cursor/category/bbox | Backend использует offset и from/to/device_id/max_accuracy_m; карта фильтрует локально |
| Игнорирование неизвестных полей | Backend отклоняет их, чтобы не терять новые данные молча |
| synced игнорируется | Backend хранит присланное значение; подтверждение — только results |
| Обязательные датчики и GPS, жёсткие диапазоны | Nullable raw-поля backend сохранены; GPS может временно отсутствовать |
| Четыре таблицы и calibrations | Две таблицы raw/processed; калибровка и история алгоритмов пока не реализованы |

Основной вариант карты — Leaflet без API-ключа. 2GIS доступен по `/web/map-2gis.html`,
но требует собственного ключа 2GIS в CFG.KEY и отдельно не проверен.

## Границы готовности

Это локальный веб-прототип: приём и импорт измерений, хранение, карта, история API,
статистика. Android-приложение и прошивка ESP32 в этой папке отсутствуют.
Их BLE-пакеты, Room и обработку sync нельзя подтвердить без исходников.
MQ-135 raw сохраняется; AQI/ppm и медицинские рекомендации не рассчитываются.
Публичное развёртывание и проверка с физическим телефоном ещё не выполнены.

## Проверка

В папке air-quality-backend:

```
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m scripts.verify_http
.\.venv\Scripts\python.exe -m alembic check
```

verify_http использует отдельную временную SQLite-БД и порт 18001.
Проверяет health, HTML, sync (null/число altitude, дубликат, частичный отказ), UTC,
неизвестный AQI и карту. Рабочая база не используется.
Предыдущая гипотеза о несовместимости httpx не подтвердилась: тесты проходят
вне ограниченной песочницы, есть только deprecation warning.
