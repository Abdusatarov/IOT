# Временная ссылка из панели

1. Откройте server-panel.cmd и нажмите «Запустить».
2. После готовности backend нажмите «Интернет-ссылка».
3. Дождитесь адреса https://….trycloudflare.com. QR переключится на этот адрес.
4. Ссылку можно скопировать кнопкой; телефон может использовать мобильный интернет.
5. «Отключить интернет» закрывает туннель и возвращает локальный QR.
   «Остановить» и закрытие панели также останавливают туннель.

Работают, пока включены ноутбук, backend и туннель. После нового запуска адрес меняется.
Первый запуск скачивает официальный cloudflared с GitHub Cloudflare, сверяет SHA-256
с digest релиза и сохраняет файл в .tools. Папка исключена из Git.
Журнал соединения: air-quality-backend/public-tunnel.log.

Публичный шлюз слушает отдельный случайный порт только на loopback и разрешает
лишь GET главной страницы, assets и используемых API чтения. POST/PUT/PATCH/DELETE,
sync, import, docs и другие пути закрыты. Отдельный локальный backend не меняется.
Показания и координаты из БД доступны всем, у кого есть ссылка. Это временный
режим демонстрации с синтетическими данными, не размещение личных маршрутов.
