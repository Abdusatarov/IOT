Проект: Air Monitor IoT — backend для сбора измерений с ESP32-C3 SuperMini через Android-приложение.

C:\Users\MBX\Documents\Project\air-quality

Стек и архитектура:
- Python 3.13.17, FastAPI, SQLAlchemy, Alembic.
- Локальная БД — SQLite `air_quality.db`; PostgreSQL предусмотрен для развёртывания.
- ESP32 передаёт датчики в Android по BLE; Android добавляет GPS, время и сохраняет данные локально. Backend принимает синхронизацию приложения по HTTP.
- `measurements` хранит исходные данные, `processed_measurements` — результат обработки.
- MQ-135 `mq135_raw` сохраняется без преобразования. AQI и ppm не рассчитываются, пока нет калибровки.

Реализованные API:
- `GET /api/v1/health` — проверка API и БД.
- `POST /api/v1/sync` — пачка измерений, 1–1000 записей. Ответ включает `accepted`, `duplicates`, `rejected` и результат для каждой строки.
- Повторная отправка безопасна: уникальность определяется `measurement_id`.
- `altitude_m` принимает `null` или число.
- `measured_at` требует ISO-8601 со временем и часовым поясом; сервер нормализует в UTC.
- Дополнительные маршруты: `/api/v1/measurements`, `/latest`, `/{measurement_id}`, `/map`, `/statistics`, `/recommendations`, а также `POST /api/v1/import`.
- Android должен отмечать `Room.synced=true` только для записей со статусом `accepted` или `duplicate`. HTTP 200 сам по себе не означает, что вся пачка принята.

- Для публичного/release-сценария нужен HTTPS и настроенный API_KEY.
- BLE и Room-код в этом backend-репозитории отсутствуют.
