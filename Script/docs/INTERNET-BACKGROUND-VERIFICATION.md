# Интернет и фоновый сбор: проверка 18.11.2026

- Android APK собран; 5 unit-тестов HTTP-контракта/подтверждений прошли; Android Lint завершился без ошибок.
- 55 тестов backend и 5 тестов интернет-шлюза прошли (60 всего; запуски выполнялись группами).
- HTTPS health=200; чтение карты=403; POST sync без ключа=401; пустая пачка с ключом=422.
- Реальный телефон: Android API 28. APK установлен поверх прежнего без очистки Room. Пользователь запустил START BACKGROUND и выключил экран.
- В foreground-службе подтверждены постоянное уведомление и partial wake lock. Системное состояние экрана Dozing наблюдалось во время сохранения и отправки.
- После исправления связи BLE -> автосохранение журнал текущего процесса содержит 12 автоматических сохранений и 12 подтверждений отправки отдельных новых записей на момент проверки. Интервал около 10 секунд; свежий GPS присутствовал.
- Ранее 9 накопленных записей также были приняты через реальную HTTPS-ссылку. На момент проверки рабочая SQLite содержит 72021 записей, integrity_check=ok; сбор может продолжаться.
- Служба и сервер оставлены включёнными. Для остановки сбора: STOP в приложении или уведомлении. Для остановки сервера: панель Script/server-panel.cmd.
- Длительный deep Doze, перезагрузка, производительские ограничения и длительная работа без USB отдельно не проверялись. Force-stop/reboot требуют повторного запуска сбора.
- Реальные координаты и времена в отчёт не включались. Ключ хранится только локально в Script/.tools и приватных настройках телефона.
- Рабочая база теперь содержит реальные GPS-измерения. Разрешение пользователя на передачу в его сервер не означает разрешение публиковать реальные маршруты в GitHub. Снимок Script/data/air_quality.db пока остаётся прежним синтетическим снимком; не обновлять публичную копию реальными данными без отдельного решения.
