═══ ЧЕСТНОСТЬ ДАННЫХ (обязательно) ═══
- MQ-135 — это raw-значение без калибровки. НИКОГДА не подписывай его как
  AQI, ppm или мкг/м³. Единица: «raw» или «усл. ед.».
- Цветной слой на карте — приблизительная интерполяция между датчиками.
  Подпись: «Приблизительная оценка между датчиками».
- Если данных нет (ветер, давление, видимость, пыльца) — удали эти блоки
  полностью, не оставляй пустышки.
- Синтетические и реальные измерения должны визуально отличаться
  (штриховка/бейдж «демо»), если в данных есть такой признак.
- Всё время показывай в одной зоне: Asia/Almaty (UTC+5). Убери смесь с UTC.

═══ ДИЗАЙН-НАПРАВЛЕНИЕ ═══
Стиль: «спокойный научный прибор». Чисто, много воздуха, данные —
главное, декора минимум. Без градиентных фонов, без неона, без теней-«облаков»,
без эмодзи в интерфейсе. Ориентиры по ощущению: Linear, Vercel dashboard,
Apple Weather.

Шрифты (Google Fonts):
- Интерфейс: Inter (400, 500, 600)
- Числа и значения датчиков: JetBrains Mono (500), с tabular-nums
Размеры: 12 / 14 / 16 / 20 / 28 / 40 px. Заголовки страниц 28, большие
числа 40, подписи 12 в приглушённом цвете.

Цвета — задай как CSS-переменные и используй ТОЛЬКО их:
Светлая тема:
  --bg: #F7F8FA;  --surface: #FFFFFF;  --border: #E4E7EC;
  --text: #101828; --text-muted: #667085;
  --accent: #0E7C86;  --accent-soft: #E0F2F3;
  --warn: #B54708; --danger: #B42318;
Тёмная тема:
  --bg: #0B0F14;  --surface: #131A22;  --border: #243040;
  --text: #E6EAF0; --text-muted: #8B98A9;
  --accent: #3CC4CF;  --accent-soft: #11313A;
  --warn: #F79009; --danger: #F97066;
Форма: радиус 12px у карточек, 8px у кнопок/инпутов, границы 1px вместо
теней. Отступы кратны 4px (8, 12, 16, 24, 32). Переходы 150ms ease.
Фокус с клавиатуры — видимая обводка 2px var(--accent).

Палитры карты (коричневая, океан, фиолетовая, закат, своя из 6 цветов)
оставь как есть по логике, но выбор палитры сделай компактным: ряд
маленьких круглых превью, а не большие карточки.

═══ СТРУКТУРА И НАВИГАЦИЯ ═══
Десктоп: узкая левая боковая панель (ширина 220px, сворачивается до 64px
с иконками). Пункты: Обзор, Карта, Анализ, Календарь, О проекте.
Внизу панели: переключатель темы. Иконки — lucide (линейные, 1.5px).
Мобильная версия (<768px): нижняя панель из 4 вкладок (Обзор, Карта,
Анализ, Календарь), «О проекте» — в верхнем меню. Все кнопки не меньше 44px.

Главная страница по умолчанию — «Обзор» (не «О проекте»). «О проекте»
показывай один раз при первом визите как компактное окно/баннер, а не
как отдельный огромный экран.

Выбор устройства — ВЕЗДЕ один и тот же компонент: выпадающий список с
поиском (combobox) + пункт «Весь город». Убери длинные ряды карточек
устройств.

Язык: убери надпись «Русский», если это не рабочий переключатель.

═══ СТРАНИЦЫ ═══
1. ОБЗОР
  - Сверху: выбор устройства + выбор периода (сегмент 24ч / 7д / 30д).
  - Ряд из 3 карточек-метрик: MQ-135 raw, Температура, Влажность.
    В каждой: крупное число (JetBrains Mono), подпись, маленькая
    дельта к предыдущему периоду (стрелка + число, цвет не обязателен).
  - Под ними большой график MQ-135 на всю ширину, ниже — мини-карта
    (высота ~280px) и ссылка «Открыть календарь».
  - Предупреждение о некалиброванных данных — тонкая плашка сверху
    (иконка info, фон --accent-soft), закрываемая.

2. КАРТА
  - Карта на весь экран (под боковой панелью), тема карты следует теме
    сайта.
  - Маркеры — круги 16px с белой обводкой, цвет по значению MQ-135.
  - Сверху по центру — плавающая панель: выбор устройства, переключатель
    «Цветной слой», слайдер времени (последние 24ч).
  - Палитры — в выдвижной панели настроек справа (иконка шестерёнки).
  - НОВОЕ: при клике на маркер открывается боковая панель сведений о
    датчике (справа на десктопе, нижний sheet на мобильном): название,

  - Легенда цветов внизу слева с подписью «raw, усл. ед.».

3. АНАЛИЗ
  - Сверху: сегмент периода (Сутки / Неделя / Месяц / Вся история),
    сводка из 4 небольших чисел (устройства, измерения, ср. температура,
    ср. влажность).
  - Слева — таблица датчиков с поиском (колонки: название, последнее

    график выбранного датчика с вкладками: MQ-135 / Температура /
    Влажность / Точность GPS.
  - Убери переключатель «MQ-135 / raw» — он дублирует одно и то же.
  - На мобильном: таблица сверху, график под ней.

4. КАЛЕНДАРЬ
  - Годовая сетка в стиле GitHub contributions: 53 колонки × 7 строк,
    квадраты 12px, радиус 3px. Цвет — шкала из 5 ступеней от
    --accent-soft до --accent; дни без данных — просто --border.
  - Над сеткой: выбор года и устройства. Под сеткой: «Дней с данными»,
    «Дней без данных», «Всего измерений».
  - Подсказка: дата, среднее значение, количество записей.
