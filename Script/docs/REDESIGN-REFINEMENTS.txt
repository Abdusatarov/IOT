Продолжаем редизайн AlmatyAir. Логику данных и backend не трогай, правим
только интерфейс. Нужно исправить 4 вещи. Делай по порядку и после
каждой пункта останавливайся и пиши, что изменено.

═══ 1. БОКОВАЯ ПАНЕЛЬ: АВТОСКРЫТИЕ ═══
Сейчас панель постоянно занимает 220px. Сделай так:
- По умолчанию панель свёрнута в узкую полосу 64px: видны только иконки
  (названия пунктов скрыты, при наведении на иконку — tooltip).
- При наведении курсора на полосу панель плавно раскрывается до 220px
  ПОВЕРХ контента (position: fixed/absolute, z-index выше контента),
  контент при этом НЕ сдвигается и не перерисовывается.
  Закрывается через ~200ms после ухода курсора. Анимация 150ms ease.
- Внизу панели кнопка-«кнопка закрепить» (pin): если нажата, панель
  остаётся раскрытой и контент сдвигается. Состояние pin сохрани в
  localStorage.
- Контент всегда имеет левый отступ 64px (если панель не закреплена).
- Мобильная версия (<768px): панели нет, вместо неё кнопка-бургер в
  верхней строке, по нажатию панель выезжает слева с затемнением фона;
  закрывается по нажатию вне панели или на пункт меню.
- Блок «MQ-135 raw · Без калибровки» внизу панели в свёрнутом виде
  показывай только точкой-индикатором.

═══ 2. КАЛЕНДАРЬ: МАСШТАБИРОВАНИЕ ═══
Сейчас сетка фиксированного размера (квадраты ~12px), прижата влево и
оставляет пустое место справа. Нужно:
- Сетка занимает всю ширину карточки. Реализуй через CSS Grid:
  grid-template-columns: repeat(53, 1fr); grid-auto-flow: column;
  grid-template-rows: repeat(7, auto); gap: 3px; а у каждой ячейки
  aspect-ratio: 1 / 1. Тогда квадраты сами растут и сжимаются вместе с
  шириной экрана.
- Подписи месяцев позиционируй по номеру недели в процентах ширины, а не
  фиксированными пикселями, чтобы они совпадали с колонками при любом
  размере. Подписи дней недели слева — отдельной узкой колонкой.
- Карточка календаря на всю ширину контента, без max-width.
- На узких экранах (<768px) сетка получает горизонтальную прокрутку с
  минимальной шириной ячейки 14px, чтобы квадраты не стали крошечными.
- Выбор дня и блок «Среднее / Записей / Мин-макс» оставь под сеткой, но
  выровняй по сетке на 3 колонки, без пустых провалов.
- Подпись «средние показания за сутки UTC» замени на единое время
  Asia/Almaty, если сервер позволяет; если нет — оставь UTC, но напиши
  это явно в одной серой строке под заголовком.

═══ 3. КАРТА: КОМПАКТНАЯ ВЕРХНЯЯ ПАНЕЛЬ ═══
Сейчас плавающая панель сверху (выбор устройства + слайдер времени)
закрывает большую часть карты и содержит всё сразу. Перепроектируй:
- Карта занимает весь экран от края до края (сейчас хорошо).
- Верхняя панель превращается в компактную «пилюлю» высотой 44px,
  шириной по содержимому (≈ 360px), слева сверху с отступом 16px:
  [выпадающий выбор устройства] [переключатель «Слой»] [иконка настроек].
  Никаких подписей «Устройство» и лишних заголовков.
- Слайдер времени вынеси в тонкую панель ВНИЗУ по центру (высота 40px,
  ширина ~ 480px): слева метка «24 ч назад», справа текущее время,
  по умолчанию свёрнута в маленькую кнопку «История» и раскрывается по
  нажатию.
- Настройки палитры (5 палитр + своя из 6 цветов) — выпадающее окно,
  привязанное к иконке настроек, а не часть основной панели.
- Легенда внизу слева: сделай компактной (высота ≤ 48px), сворачиваемой.
- Кнопки зума оставь справа, но с отступом, чтобы не пересекались с
  нижней панелью.
- Все плавающие панели: фон var(--surface) с прозрачностью 92% и
  backdrop-filter: blur(8px), граница 1px, радиус 12px.

═══ 4. АНАЛИЗ: ГРАФИК НА ВЕСЬ ЭКРАН ═══
Нужна возможность растянуть график на весь экран:
- В правом верхнем углу карточки графика добавь кнопку «Во весь экран»
  (иконка maximize). В режиме полного экрана:
  • карточка графика получает position: fixed; inset: 0; z-index: 1000,
    фон var(--bg); график занимает всю высоту окна минус верхняя
    панель управления (вкладки MQ-135 / Температура / Влажность /
    Точность GPS, кнопки зума, выбор периода, кнопка закрытия);
  • после входа в режим вызови перерасчёт размера графика
    (resize / ResizeObserver), иначе он останется старого размера;
  • закрытие: кнопка «Закрыть» (иконка minimize) и клавиша Esc;
  • боковая панель и таблица устройств в этот момент скрыты.
- Дополнительно: кнопка «Скрыть список» над таблицей устройств, по
  нажатию график растягивается на всю ширину страницы (без полного
  экрана). Состояние запоминай.
- Если используется Fullscreen API, добавь запасной вариант через CSS
  (для iOS Safari), на случай если API недоступен.
- График в полноэкранном режиме должен сохранять зум и выбранный период.
- Исправь линию графика: сейчас при отсутствии данных (пропуск между
  30 октября и 19 ноября) линия тянется прямой через весь промежуток.
  Разрывай линию на пропусках (null/gap), вместо соединения точек
  прямой. Порог пропуска: больше 6 часов без записей.

═══ ПРОВЕРКА В КОНЦЕ ═══
Проверь на ширинах 360px, 768px, 1280px, 1920px, в светлой и тёмной
теме: нет горизонтальной прокрутки у страницы, ничего не перекрывается,
панель при наведении раскрывается поверх контента, график и календарь
масштабируются при изменении размера окна.
