# AlmatyAir

Обновлённый интерфейс проекта React + TypeScript + Vite по предоставленным скриншотам.

## Запуск

Требуется Node.js 22.12+ (или 24 LTS).

```bash
npm ci
npm run dev
```

## Проверка и сборка

```bash
npm run lint
npm run build
npm run preview
```

В архиве есть исходники и готовая папка dist. Для просмотра нужен HTTP-сервер; двойной щелчок по dist/index.html не подходит.

## Разделы

- Обзор: районы, индикатор AQI, погода, карта и график.
- Карта: масштабирование, карточки 84 демонстрационных датчиков, фильтр района и ползунок времени.
- Подробнее → Аналитика: сводные демонстрационные показатели и графики.
- Подробнее → Календарь: выбор года и PM2.5/PM10, подсказки по датам.
- Нажатие на логотип открывает стартовую страницу.
- Переключатель темы сохраняет выбор в браузере. Интерфейс адаптирован для телефона.

## Данные и ограничения

Все показания и координаты датчиков сгенерированы для демонстрации интерфейса. Погода и сводные показатели — примеры, а не текущие измерения. Временной ползунок моделирует значения. История включает синтетический полный год, включая будущие даты. Перевод AQI в концентрацию упрощён и не предназначен для реального мониторинга. API и авторизация отсутствуют в исходном проекте и не добавлены. Для подключения реальных данных замените src/data.ts, данные графиков и календаря, погодные и сводные показатели в App.tsx.

Карта использует онлайн-тайлы CARTO / OpenStreetMap; нужен интернет. При отсутствии сети остальные разделы работают с локальными демоданными. Скриншоты использованы как визуальные ориентиры; бренд проекта AlmatyAir сохранён.

## Состав

src/App.tsx — страницы и состояния; src/App.css — темы и адаптивность; src/AirMap.tsx — Leaflet; src/AirChart.tsx — Recharts; src/data.ts — демодатчики. Конфигурация и lock-файл включены. node_modules и файлы IDE исключены из поставки.
