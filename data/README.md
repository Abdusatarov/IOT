# База для демонстрации

air_quality.db содержит сохранённые измерения проекта, включая синтетический
30-дневный набор. Снимок создаётся из локальной рабочей SQLite-базы командой
`python snapshot-database.py` в корне проекта.

После клонирования скопируйте data/air_quality.db в air-quality-backend/air_quality.db
перед запуском backend. Если в целевой папке уже есть база, сначала сохраните её
отдельную копию. Рабочая база, журналы SQLite и резервные копии исключены из Git.

Репозиторий публичный. Перед добавлением новых данных проверьте, что их разрешено
публиковать, в том числе идентификаторы устройств и координаты измерений.
